monorepo at [`stevegsax/forge`](https://github.com/stevegsax/forge),
under `apps/pbook/`, with full history imported (tags renamed
`v*` → `pbook-v*`). See forge's `docs/DECISIONS.md` (D98).

- **Tags `v0.1.0`–`v0.2.1`** stay fetchable as pinned `uvx` targets
  (the pbook skill pins `v0.2.1` until forge's sax-llm sibling is
  absorbed and the `#subdirectory=apps/pbook` form resolves).
- **`diataxis/`** (the generated Hugo docs site) exists only here — it
  was excluded from the imported history as a disposable artifact.
