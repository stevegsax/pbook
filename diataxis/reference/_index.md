Reference documents describe pbook's surface area: commands, models, schemas, and workflow definitions. Consult them to look up a specific detail, not to learn how something fits together.

- [Tag System Reference](tags/) — the five tag namespaces, valid values, validation rules, and tag inference from file extensions and keywords.
- [Data Model Reference](data-model/) — Pydantic models (PlaybookEntry, FeedbackInput, PushExperienceInput, RetrievalInput, RetrievalResult, SessionInfo), entry types, and the database schema.
- [CLI Reference](cli/) — every `pbook` subcommand with synopsis, options, defaults, and examples.
- [Temporal Workflows Reference](workflows/) — workflow inputs, outputs, step tables, activity timeouts, and cross-queue interaction with forge.
